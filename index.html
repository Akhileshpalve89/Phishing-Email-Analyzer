EmailGuard Pro

Phishing Email Threat Analyzer browser extension for Gmail and Outlook.

GitHub Repository Netlify Live Demo (Add Link)

What it does

  • Extracts email content from webmail clients.
  • Checks suspicious URLs with VirusTotal.
  • Evaluates sender domain risk with AbuseIPDB.
  • Shows a simple safe/suspicious/danger state in popup UI.

How to run locally

  • Download this repository.
  • Open chrome://extensions.
  • Enable Developer Mode and click Load unpacked.
  • Select this project folder.

Tip: replace the Netlify button with your deployed site URL for a complete portfolio demo.
